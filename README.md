# Employee Management System

A console-based Employee Management System developed using Python and MySQL.

## Features
- Add Employee
- Delete Employee
- Search Employee
- Edit Employee Details
- Display Employee List
- Promote Employee
- Change Password

## Technologies Used
- Python
- MySQL
- PyMySQL
- Colorama
- Pwinput
- Time
- Tqdm 
- Sys

## Description
This project allows users to manage employee records through a simple
console-based interface. Employee information is stored and managed
using a MySQL database.
